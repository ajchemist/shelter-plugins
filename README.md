# shelter-plugins

A [Lune](https://shelter.uwu.network/guides/lune)-based [Shelter](https://github.com/uwu/shelter) plugin repository. Plugins are distributed via GitHub Pages and can be installed by URL.

## Plugins

| Plugin | Description |
|--------|-------------|
| [MarkdownTableRenderer](plugins/MarkdownTableRenderer/) | Renders Markdown tables in Discord messages |
